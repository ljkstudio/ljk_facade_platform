(`RHINO_PACKAGE_DIRS` = 빌드 출력 폴더)으로 다시 띄웠고, 그 폴더가
`Grasshopper.Folders.AssemblyFolders` 에 **정상 반영되는 것까지 확인했다.**
그런데도 `ComponentServer.Libraries == 0`, `ObjectProxies == 0` 이다 —
스크립트로 `_Grasshopper` 를 태워 편집기가 열리고(`DocumentEditor` 가

까지 불렀는데도 라이브러리 스캔이 일어나지 않는다.

**원인이 밝혀졌다 (같은 날 해결).** 두 가지가 겹쳐 있었다.

⑴ **동기 호출이 로더를 굶긴다.** `PlugIn.LoadPlugIn()` 이나
`RhinoApp.RunScript("_Grasshopper")` 를 브리지 스크립트에서 부르면 우리
스크립트가 UI 스레드를 쥔 채 GH 로더를 기다리게 되어 `IsLoading=True` 인
채로 멈춘다(라이브러리 0, 예외 0). **`RhinoApp.SendKeystrokes("Grasshopper",
True)` 는 명령을 큐에 넣고 즉시 반환하므로 스레드를 놓아준다** — 이쪽이 답이다.

⑵ **모달 대화상자가 로딩을 막고 있었다.** 화면에 GH `File Conflict` 가
떠 있었다 — 개발 빌드(`bin\Debug`, 58.4 KB)와 **설치본 껍데기**
(`packages\8.0\ljks-adaptive-mold\0.1.0\`, 8.2 KB)가 같은 이름이라
어느 것을 Load 할지 묻는다. 왼쪽(개발 빌드) Load 를 눌러야 한다.
이어서 `Select Grasshopper-Tekla Link Version`(Tekla 미실행) 과
`Unable to initialize the Grasshopper-Tekla live link`(우리는 `/netcore`
로 띄우므로 당연) 가 뜬다 — 둘 다 확인만 누르면 된다.

**즉 브리지 상태만 보면 "GH 로드됨" 인데 화면에는 대화상자가 떠 있을 수
있다.** 로딩이 안 끝나면 `ComponentServer.IsLoading` 을 먼저 보고,
`True` 인데 진행이 없으면 **화면의 모달을 의심할 것.**

**같이 확인된 것 둘:**
- `mcpstart` 는 이 세션에서 **필요 없었다** — 브리지가 왕복까지 됐다.

## Global Constraints

M2a·M2b 의 제약이 **전부 그대로 유효하다.** 아래는 그중 M3 에서 특히 걸리는 것과 M3 에서 새로 붙는 것이다.

- **`Core` 는 이 마일스톤에서 고치지 않는다.** 계산이 바뀌면 M2b 의 대조가 무효가 된다. `Core` 를 고쳐야 할 이유가 생기면 **멈추고 픽스처부터 다시 뽑는다.**
- **`Core` 5대 규약** (스펙 §3.1): Grasshopper·`RhinoDoc`·`IGH_DataAccess` 미참조. **어댑터는 `AdaptiveMold.GH` 안에만 있다.**
- **NuGet 은 `8.0.23304.9001` 고정.** 와일드카드 금지 — `.gha` 가 조용히 등록 거부된다(J-015 TRAP-03). `PackagingContractTests` 가 막는다.
- **배포 태그는 `rh8_0-win`.** `yak build --platform win` + NuGet 고정, 둘 다 맞아야 나온다. **파일명의 태그가 곧 진단이다.**
- **패키지 id 는 `ljks-adaptive-mold`.** `yak spec` 이 만드는 `LJKS-AdaptiveMold` 를 쓰면 안 된다(J-015 TRAP-01). **최초 업로드의 대소문자가 영구 고정된다.**
- **경로는 `Grasshopper.Instances.ComponentServer.FindAssembly(id).Location`.** `Assembly.Location` 금지 — COFF 메모리 로딩이 켜진 사용자에게 빈 문자열이라 **PC 마다 갈리는 재현 불가 버그**가 된다(스펙 §4.2).
- **GH 툴팁은 평문이다.** 마크다운(`**`)을 쓰면 기호가 그대로 보인다. 줄바꿈 `\n` 만 먹는다.
- **이름은 영어, 설명은 한국어.** 컴포넌트·파라미터 **이름**은 영어 유지(픽스처 JSON 키·C# 프로퍼티·문서에 동시에 나타난다). 툴팁·매뉴얼·런타임 메시지는 한국어, **단 파라미터명·수치·API 이름은 원문 그대로.**
- **문서에 숫자를 손으로 적지 않는다.** 생성하거나 안 적는다(자동검사 5). 실측치를 쓸 때는 저널 링크를 단다.
- **병렬화·비동기 금지.** `Task.Run`·`Parallel.For` 를 쓰지 않는다. T8 실측 18.6 ms.
- **테스트는 Rhino 안에서 돈다.** `dotnet build` **성공을 눈으로 확인한 뒤** `python adaptive_mold/tools/run_csharp_tests.py`.
- **`mcpstart` 와 `Grasshopper` 는 사람이 친다.** 포트 개방은 준비 신호가 아니다.
- **저널 번호는 `J-017`.** 새 저널 전에 `git ls-tree --name-only feature/unfold-v1 docs/journal/` 로 다른 브랜치를 확인할 것.

```csharp
using System;
using System.Collections.Generic;
using System.Reflection;
using System.Text.Json;

namespace AdaptiveMold.GH
{
    /// <summary>
    /// 임베드된 <c>docs/params.ko.json</c> 에서 <c>AMv1 Pins</c> 의 툴팁을 읽는다.
    ///
    /// **없는 이름에 예외를 던지지 않는다.** 던지면 정적 생성자나 파라미터
    /// 등록에서 터지고, Grasshopper 는 그런 컴포넌트를 **아무 진단 없이
    /// 팔레트에서 뺀다** — J-015 TRAP-03 에서 이미 한 번 당한 실패 방식이다.
    /// 대신 눈에 띄는 문자열을 돌려주고, 그것을 자동검사 1·2 가 잡는다.
    /// 사라지는 것보다 이상한 툴팁이 낫다.
    /// </summary>
    public static class ParamDocs
    {
        public const string Component = "AMv1 Pins";
        public const string MissingPrefix = "[설명 없음]";

        const string ResourceName = "AdaptiveMold.GH.params.ko.json";

        static readonly Dictionary<string, string> _inputs = new Dictionary<string, string>();
        static readonly Dictionary<string, string> _outputs = new Dictionary<string, string>();
        static readonly string _loadError;

        static ParamDocs()
        {
            try
            {
                var asm = typeof(ParamDocs).Assembly;
                using (var s = asm.GetManifestResourceStream(ResourceName))
                {
                    if (s == null)
                    {
                        _loadError = $"임베드 리소스 {ResourceName} 이 없다";
                        return;
                    }
                    using (var doc = JsonDocument.Parse(s))
                    {
                        if (!doc.RootElement.TryGetProperty(Component, out var comp))
                        {
                            _loadError = $"params.ko.json 에 \"{Component}\" 절이 없다";
                            return;
                        }
                        Fill(comp, "inputs", _inputs);
                        Fill(comp, "outputs", _outputs);
                    }
                }
            }
            catch (Exception e)
            {
                _loadError = e.Message;
            }
        }

        static void Fill(JsonElement comp, string key, Dictionary<string, string> into)
        {
            if (!comp.TryGetProperty(key, out var section)) return;
            foreach (var p in section.EnumerateObject())
                into[p.Name] = p.Value.GetString();
        }

        public static IReadOnlyDictionary<string, string> Inputs => _inputs;
        public static IReadOnlyDictionary<string, string> Outputs => _outputs;

        public static string In(string name) => Lookup(_inputs, "inputs", name);
        public static string Out(string name) => Lookup(_outputs, "outputs", name);

        static string Lookup(Dictionary<string, string> d, string kind, string name)
        {
            if (d.TryGetValue(name, out var v) && !string.IsNullOrWhiteSpace(v))
                return v;

            return $"{MissingPrefix} params.ko.json 의 \"{Component}\".{kind} 에 "
                 + $"\"{name}\" 이 없다."
                 + (_loadError == null ? "" : $" (로드 오류: {_loadError})");
        }
    }
}
```

```csharp
            Brep target = null;
            var basePlane = Plane.WorldXY;
            double width = 1000.0, length = 1000.0, spacing = 200.0;
            double maxHeight = 400.0, minHeight = 0.0;

            DA.GetData(1, ref basePlane);
            DA.GetData(2, ref width);
            DA.GetData(3, ref length);
            DA.GetData(4, ref spacing);

                case MoldMessageLevel.Error: return GH_RuntimeMessageLevel.Error;
                case MoldMessageLevel.Warning: return GH_RuntimeMessageLevel.Warning;
                default: return GH_RuntimeMessageLevel.Remark;
            }
        }

            return r.Info + $"\nElapsed:     {ms:F0} ms";
        }
```

```python
#! /usr/bin/env python3
# -*- coding: utf-8 -*-
"""AMv1 Pins 아이콘을 생성한다 — 손으로 그리지 않는다.

그림: 어두운 바탕 위에 높이가 다른 핀 다섯 개, 그 위를 지나는 목표 곡선.
그것이 이 컴포넌트가 하는 일 전부다(곡면 -> 핀 높이).

    python adaptive_mold/tools/make_icons.py

출력: plugin/AdaptiveMold.GH/Resources/icon24.png (컴포넌트)
      plugin/AdaptiveMold.GH/Resources/icon64.png (Yak 매니페스트)
"""

import os

from PIL import Image, ImageDraw

HERE = os.path.dirname(os.path.abspath(__file__))
REPO = os.path.normpath(os.path.join(HERE, "..", ".."))
OUT = os.path.join(REPO, "plugin", "AdaptiveMold.GH", "Resources")

BG = (32, 38, 46, 255)
PIN = (150, 160, 172, 255)
CURVE = (255, 176, 59, 255)

# 핀 5개의 상대 높이 (0~1). 가운데가 높은 완만한 곡면.
HEIGHTS = [0.30, 0.62, 0.86, 0.66, 0.34]


def draw(size):
    """size 배수로 그린 뒤 줄인다 — 24px 에 직접 그리면 계단이 심하다."""
    ss = 8
    n = size * ss
    img = Image.new("RGBA", (n, n), (0, 0, 0, 0))
    d = ImageDraw.Draw(img)

    r = int(n * 0.18)
    d.rounded_rectangle([0, 0, n - 1, n - 1], radius=r, fill=BG)

    pad = n * 0.16
    inner = n - 2 * pad
    base_y = n - pad
    pin_w = max(2, int(inner / (len(HEIGHTS) * 2.2)))

    tops = []
    for i, h in enumerate(HEIGHTS):
        cx = pad + inner * (i + 0.5) / len(HEIGHTS)
        top_y = base_y - inner * h
        d.rectangle([cx - pin_w / 2.0, top_y, cx + pin_w / 2.0, base_y], fill=PIN)
        tops.append((cx, top_y))

    d.line(tops, fill=CURVE, width=max(2, int(n * 0.045)), joint="curve")

    return img.resize((size, size), Image.LANCZOS)


def main():
    if not os.path.isdir(OUT):
        os.makedirs(OUT)
    for size in (24, 64):
        p = os.path.join(OUT, "icon%d.png" % size)
        draw(size).save(p, "PNG", optimize=True)
        print("%s  %d bytes" % (p, os.path.getsize(p)))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
def make_flat(z_height, size):
    plane = rg.Plane(rg.Point3d(0, 0, z_height), rg.Vector3d.ZAxis)
    iv = rg.Interval(-size / 2.0, size / 2.0)
    return rg.PlaneSurface(plane, iv, iv).ToBrep()

def add_brep_param(doc, brep, x, y, nick):
    p = ghp.Param_Brep()
    p.NickName = nick
    p.Name = nick
    p.PersistentData.Append(ght.GH_Brep(brep))
    p.Attributes.Pivot = pt(x, y)
    doc.AddObject(p, False)
    return p


def add_plane_param(doc, plane, x, y, nick):
    p = ghp.Param_Plane()
    p.NickName = nick
    p.Name = nick
    p.PersistentData.Append(ght.GH_Plane(plane))
    p.Attributes.Pivot = pt(x, y)
    doc.AddObject(p, False)
    return p


def add_slider(doc, value, lo, hi, x, y, nick):
    s = ghs.GH_NumberSlider()
    s.CreateAttributes()
    s.Slider.Minimum = System.Decimal(float(lo))
    s.Slider.Maximum = System.Decimal(float(hi))
    s.Slider.DecimalPlaces = 0
    s.SetSliderValue(System.Decimal(float(value)))
    s.NickName = nick
    s.Attributes.Pivot = pt(x, y)
    doc.AddObject(s, False)
    return s


def add_toggle(doc, value, x, y, nick):
    t = ghs.GH_BooleanToggle()
    t.CreateAttributes()
    t.Value = bool(value)
    t.NickName = nick
    t.Attributes.Pivot = pt(x, y)
    doc.AddObject(t, False)
    return t


def add_panel(doc, text, x, y, w=320, h=180):
    p = ghs.GH_Panel()
    p.CreateAttributes()
    p.UserText = text
    p.Attributes.Pivot = pt(x, y)
    p.Attributes.Bounds = System.Drawing.RectangleF(float(x), float(y), float(w), float(h))
    doc.AddObject(p, False)
    return p


def add_pins(doc, x, y):
    obj = gh.Instances.ComponentServer.EmitObject(PINS_GUID)
    if obj is None:
        raise RuntimeError(
            "AMv1 Pins 를 만들지 못했다. .gha 가 등록돼 있지 않다 — "
            "RHINO_PACKAGE_DIRS 또는 패키지 설치를 확인할 것.")
    obj.CreateAttributes()
    obj.Attributes.Pivot = pt(x, y)
    doc.AddObject(obj, False)
    return obj


def wire(target, index, source):
    target.Params.Input[index].AddSource(source)


def save(doc, name):
    if not os.path.isdir(OUT_DIR):
        os.makedirs(OUT_DIR)
    path = os.path.join(OUT_DIR, name)
    io_ = ghk.GH_DocumentIO(doc)
    ok = io_.SaveQuiet(path)
    size = os.path.getsize(path) if os.path.exists(path) else -1
    log("[%s] %s  %d bytes  objects=%d" % ("OK" if ok else "FAIL", name, size, doc.ObjectCount))
    return ok
```

```python
"""자동검사 4 — 예제 .gh 의 결과가 골든 픽스처와 맞는지 본다.

    python adaptive_mold/tools/check_examples.py

    ("02_coverage.gh", "T4_small_surface.json"),
    ("03_clamping.gh", "T3_hemisphere.json"),
    ("05_parity.gh", "T3_hemisphere.json"),

                      "am_examples_result.json")

# Rhino 안에서 돌 IronPython 2.7 코드. 한글 print 금지 — 파일로 남긴다.
BRIDGE = r'''
import io, json, os, traceback
import Grasshopper.Kernel as ghk

out = []
folder = r"{folder}"
for name in {names}:
    row = {{"file": name}}
    try:
        dio = ghk.GH_DocumentIO()
        opened = dio.Open(os.path.join(folder, name))
        doc = dio.Document
        doc.Enabled = True
        doc.NewSolution(True)

        pins = None
        for o in doc.Objects:
            if o.Name == "AMv1 Pins":
                pins = o
        if pins is None:
            row["error"] = "AMv1 Pins not found"
            out.append(row); continue

        def branch_values(idx):
            tree = pins.Params.Output[idx].VolatileData
            vals = []
            for i in range(tree.PathCount):
                for v in tree.get_Branch(i):
                    vals.append(v)
            return vals

        heights = branch_values(0)
        clamps = branch_values(3)
        exts = branch_values(4)

        row["opened"] = bool(opened)
        row["pin_count"] = len(heights)
        row["clamped"] = len([c for c in clamps if c.Value])
        row["in_extension"] = len([e for e in exts if e.Value])
    except Exception:
        row["error"] = traceback.format_exc()
    out.append(row)

f = io.open(r"{result}", "w", encoding="utf-8")
try:
    f.write(unicode(json.dumps(out)))
finally:
    f.close()
'''


def main():
    folder = os.path.join(REPO, "plugin", "examples")
    names = [n for n, _ in PAIRS]

    if os.path.exists(RESULT):
        os.remove(RESULT)

    code = BRIDGE.format(folder=folder.replace("\\", "\\\\"),
                         names=json.dumps(names),
                         result=RESULT.replace("\\", "\\\\"))

    r = Rhino(timeout=300)
    try:
        resp = r.py(code)
        if not resp.get("result", {}).get("success"):
            print("[실패] 브리지 실행이 깨졌다:", str(resp)[:400])
            return 2
    finally:
        r.close()

    if not os.path.exists(RESULT):
        print("[실패] 결과 파일이 없다 — Grasshopper 가 로드돼 있는지 확인할 것.")
        return 2

    rows = json.load(io.open(RESULT, encoding="utf-8"))
    by_file = dict((row["file"], row) for row in rows)

    bad = 0
    for name, fixture in PAIRS:
        row = by_file.get(name, {})
        if "error" in row:
            print("[FAIL] {}: {}".format(name, row["error"].splitlines()[-1]))
            bad += 1
            continue

        fx = json.load(io.open(os.path.join(REPO, "plugin", "fixtures", fixture),
                               encoding="utf-8"))["summary"]

        diffs = []
        for key in ("pin_count", "clamped", "in_extension"):
            if row.get(key) != fx[key]:
                diffs.append("{}: 예제 {} vs 픽스처 {}".format(key, row.get(key), fx[key]))

        if diffs:
            print("[FAIL] {} <-> {}".format(name, fixture))
            for d in diffs:
                print("       " + d)
            bad += 1
        else:
            print("[OK]   {:<16} pins={} clamped={} ext={}".format(
                name, row["pin_count"], row["clamped"], row["in_extension"]))

    print("검사 {}건 중 실패 {}건".format(len(PAIRS), bad))
    return 1 if bad else 0


if __name__ == "__main__":
    sys.exit(main())
```

```markdown
목표 곡면을 재현하는 핀 몰드(다점프레스)의 액추에이터 높이를 역산한다.

단위는 전부 mm 다. 핀 순서는 `idx = j * nx + i` — **X(i)가 먼저 변한다.**

## 알아야 막지 않는 것 일곱

### 원점은 몰드의 중심이 아니라 모서리다

`base_plane` 을 비우면 WorldXY 가 되고, 격자는 그 원점에서 **+X · +Y 로만**
뻗는다. 원점을 중심으로 만든 곡면을 물리면 1/4만 겹치는데 경고는 없다.
곡면을 가운데 두려면 평면을 `(-width/2, -length/2)` 로 옮긴다.

### `max_height` 는 클램프 한계이기 전에 위치를 정하는 값이다

Phase B 가 평균 높이를 `(min_height + max_height) / 2` 로 옮긴 **뒤에**
계산이 시작된다. 그래서 `max_height` 를 키우면 여유가 생기는 것이 아니라
곡면이 통째로 올라간다. `03_clamping.gh` 의 슬라이더로 직접 만져 볼 것.

### 클램핑은 "계산은 됐지만 못 만든다"는 뜻이다

`clamp_flags` 가 `True` 인 핀의 높이는 목표가 아니라 한계값이다. 그 지점의
곡면은 재현되지 않는다. 하나라도 있으면 Warning 이 뜨고 `info` 의 `Clamped`
줄에 개수가 나온다.

### 이 파이프라인은 절대 실패하지 않는다

곡면이 그리드를 안 덮어도 폴백이 4단이라 모든 핀에 숫자가 들어간다. 빗나간
핀에는 결국 `(min_height + max_height) / 2` 가 들어가는데, 그러면 다른 핀과
똑같아 보인다. **그래서 `extension_flags` 를 봐야 한다.**

### 폴리서피스는 반쯤 섞인다

Phase C 는 첫 face 만 쓰고 Phase B·D 는 Brep 전체를 쓴다. face 가 둘 이상이면
경고가 뜬다 — 단일 face 로 합치거나 face 마다 따로 돌릴 것.

### `spacing` 이 `width` 를 안 나누면 남는 폭에 핀이 없다

`nx = floor(width / spacing) + 1` 이다. 남는 폭이 있으면 Remark 로 알린다.

거리의 절댓값을 쓰므로 곡면이 그리드 **아래**에 있어도 높이는 양수다.
```

```python
import sys

def build_table():
    docs = json.load(io.open(PARAMS, encoding="utf-8"))[COMPONENT]
    out = []
    for kind, title in (("inputs", "입력"), ("outputs", "출력")):
        out.append("")

        out.append("")
        out.append("| 이름 | 설명 |")
        out.append("|---|---|")
        for name, text in docs[kind].items():

    head, rest = src.split(BEGIN, 1)
    _, tail = rest.split(END, 1)

def inline(text):
    text = html.escape(text)
    text = re.sub(r"`([^`]+)`", r"<code>\1</code>", text)
    text = text.replace("&lt;br&gt;", "<br>")
    return text


def md_to_html(md):
    lines = md.split("\n")
    out, i, unknown = [], 0, []

    while i < len(lines):
        raw = lines[i]
        line = raw.rstrip()

        if not line.strip():
            i += 1
            continue

        if line.startswith("<!--"):
            i += 1
            continue

        m = re.match(r"^(#{1,3}) (.+)$", line)
        if m:
            lvl = len(m.group(1))
            out.append("<h%d>%s</h%d>" % (lvl, inline(m.group(2)), lvl))
            i += 1
            continue

        if line.startswith("|"):
            rows = []
            while i < len(lines) and lines[i].startswith("|"):
                rows.append(lines[i])
                i += 1
            cells = [[c.strip() for c in r.strip().strip("|").split("|")] for r in rows]
            body = [r for r in cells if not all(set(c) <= set("-: ") for c in r)]
            out.append("<table>")
            if body:
                out.append("<tr>" + "".join("<th>%s</th>" % inline(c) for c in body[0]) + "</tr>")
                for r in body[1:]:
                    out.append("<tr>" + "".join("<td>%s</td>" % inline(c) for c in r) + "</tr>")
            out.append("</table>")
            continue

        m = re.match(r"^(\d+)\. (.+)$", line)
        if m:
            out.append("<ol>")
            while i < len(lines) and re.match(r"^\d+\. ", lines[i]):
                out.append("<li>%s</li>" % inline(re.sub(r"^\d+\. ", "", lines[i])))
                i += 1
            out.append("</ol>")
            continue

        if line.startswith("- "):
            out.append("<ul>")
            while i < len(lines) and lines[i].startswith("- "):
                out.append("<li>%s</li>" % inline(lines[i][2:]))
                i += 1
            out.append("</ul>")
            continue

        if re.match(r"^[A-Za-z0-9가-힣`(\"'\[*]", line):
            para = []
            while i < len(lines) and lines[i].strip() and not re.match(
                    r"^(#{1,3} |\||- |\d+\. |<!--)", lines[i]):
                para.append(lines[i].strip())
                i += 1
            out.append("<p>%s</p>" % inline(" ".join(para)))
            continue

        unknown.append("%d: %s" % (i + 1, line[:60]))
        i += 1

    if unknown:
        raise SystemExit("변환기가 모르는 줄이 있다 (조용히 뭉개지 않는다):\n  "
                         + "\n  ".join(unknown))

    return ("<!doctype html>\n<html lang=\"ko\">\n<head>\n<meta charset=\"utf-8\">\n"
            "<title>AMv1 Pins — 사용 설명서</title>\n<style>%s</style>\n</head>\n<body>\n%s\n"
            "</body>\n</html>\n" % (CSS, "\n".join(out)))


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--check", action="store_true")
    args = ap.parse_args()

    md = render_md()
    htm = md_to_html(md)

    if args.check:
        cur_md = io.open(MANUAL_MD, encoding="utf-8").read()
        cur_htm = io.open(MANUAL_HTML, encoding="utf-8").read() \
            if os.path.exists(MANUAL_HTML) else ""
        bad = []
        if cur_md != md:
            bad.append(MANUAL_MD)
        if cur_htm != htm:
            bad.append(MANUAL_HTML)
        if bad:
            print("[FAIL] 생성 결과가 커밋본과 다르다: %s" % ", ".join(bad))
            print("       python adaptive_mold/tools/gen_manual.py 를 돌리고 커밋할 것.")
            return 1
        print("[PASS] 매뉴얼이 정본과 일치한다")
        return 0

    io.open(MANUAL_MD, "w", encoding="utf-8").write(md)
    d = os.path.dirname(MANUAL_HTML)
    if not os.path.isdir(d):
        os.makedirs(d)
    io.open(MANUAL_HTML, "w", encoding="utf-8").write(htm)
    print("생성: %s" % MANUAL_MD)
    print("생성: %s (%d bytes)" % (MANUAL_HTML, len(htm.encode("utf-8"))))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
#! /usr/bin/env python3
# -*- coding: utf-8 -*-
"""자동검사 5 — 문서에 적힌 숫자·경로가 실제와 맞는지 본다.

도움말이 코드와 어긋나면 없느니만 못하다. 이미 어긋난 증거가 있었다:
gh_components/README.md 가 설명 '125개' 라고 적었는데 실제는 153개였다.

**규칙은 "숫자를 적지 말라"가 아니라 "적었으면 검사하라"다.** 검사할 수
없는 숫자는 애초에 적지 않는다.

    python adaptive_mold/tools/check_doc_numbers.py
"""

import io
import json
import os
import re
import sys

HERE = os.path.dirname(os.path.abspath(__file__))
REPO = os.path.normpath(os.path.join(HERE, "..", ".."))

try:
    sys.stdout.reconfigure(encoding="utf-8")
except Exception:
    pass


def param_doc_count():
    docs = json.load(io.open(os.path.join(REPO, "docs", "params.ko.json"), encoding="utf-8"))
    return sum(len(v.get("inputs", {})) + len(v.get("outputs", {})) for v in docs.values())


def fixture_count():
    d = os.path.join(REPO, "plugin", "fixtures")
    return len([n for n in os.listdir(d) if n.startswith("T") and n.endswith(".json")])


CHECKS = [
    # (문서, 정규식, 실제값을 주는 함수, 무엇인지)
    ("gh_components/README.md", r"설명\s*(\d+)\s*개", param_doc_count, "툴팁 설명 개수"),
    ("docs/manual/AMv1-Pins.ko.md", r"골든 픽스처\s*(\d+)\s*개", fixture_count, "픽스처 개수"),
]

# 링크가 가리키는 경로가 실재하는지. 상대경로만 본다.
LINK_DOCS = [
    "gh_components/README.md",
    "adaptive_mold/README.md",
    "docs/manual/AMv1-Pins.ko.md",
]
LINK_RE = re.compile(r"\[[^\]]*\]\(([^)#:]+)\)")


def main():
    bad = 0

    for rel, pattern, actual_fn, what in CHECKS:
        path = os.path.join(REPO, rel)
        if not os.path.exists(path):
            continue
        text = io.open(path, encoding="utf-8").read()
        actual = actual_fn()
        for m in re.finditer(pattern, text):
            written = int(m.group(1))
            if written != actual:
                print("[FAIL] {}: {} 를 {} 로 적었는데 실제는 {}".format(
                    rel, what, written, actual))
                bad += 1

    for rel in LINK_DOCS:
        path = os.path.join(REPO, rel)
        if not os.path.exists(path):
            continue
        base = os.path.dirname(path)
        for m in LINK_RE.finditer(io.open(path, encoding="utf-8").read()):
            target = m.group(1).strip()
            if target.startswith(("http://", "https://", "mailto:")):
                continue
            if not os.path.exists(os.path.normpath(os.path.join(base, target))):
                print("[FAIL] {}: 없는 것을 가리킨다 -> {}".format(rel, target))
                bad += 1

    if bad:
        print("어긋난 곳 {}건. 숫자는 생성하거나 안 적는다.".format(bad))
        return 1
    print("[PASS] 문서의 숫자·링크가 실제와 맞는다")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
#! /usr/bin/env python3
# -*- coding: utf-8 -*-
"""`.yak` 을 만든다 — 그리고 **파일명의 태그를 검사한다.**

배포 태그가 `rh8_0-win` 이 아니면 잘못 빌드된 것이다. 두 가지가 동시에
맞아야 나온다: `yak build --platform win` 과 NuGet 8.0 고정.
`rh8_34-win` 같은 것이 나오면 Grasshopper 가 **조용히 등록을 거부한다**
(J-015 TRAP-03). 파일명이 곧 진단이다.

    python adaptive_mold/tools/build_yak.py           # 빌드만
    python adaptive_mold/tools/build_yak.py --deploy  # 로컬 소스 폴더로 복사

배포 폴더: %LOCALAPPDATA%\\LJKS\\packages
Rhino 쪽 등록: Options > Advanced > Rhino.Options.PackageManager.Sources
"""

import argparse
import glob
import os
import re
import shutil
import subprocess
import sys
import xml.etree.ElementTree as ET

HERE = os.path.dirname(os.path.abspath(__file__))
REPO = os.path.normpath(os.path.join(HERE, "..", ".."))

GH_CSPROJ = os.path.join(REPO, "plugin", "AdaptiveMold.GH", "AdaptiveMold.GH.csproj")
SLN = os.path.join(REPO, "plugin", "LjksAdaptiveMold.sln")
PKG = os.path.join(REPO, "plugin", "package")
STAGE = os.path.join(PKG, "stage")
DIST = os.path.join(PKG, "dist")
BIN = os.path.join(REPO, "plugin", "AdaptiveMold.GH", "bin", "Release", "net7.0-windows")
YAK = r"C:\Program Files\Rhino 8\System\yak.exe"

DEPLOY = os.path.join(os.environ.get("LOCALAPPDATA", ""), "LJKS", "packages")

EXPECTED_TAG = "rh8_0-win"

try:
    sys.stdout.reconfigure(encoding="utf-8")
except Exception:
    pass


def version():
    v = ET.parse(GH_CSPROJ).getroot().find(".//Version")
    if v is None:
        raise SystemExit("csproj 에 <Version> 이 없다 — 패키지 버전의 정본이다")
    return v.text.strip()


def run(cmd, cwd=None):
    print("$ " + " ".join(cmd))
    p = subprocess.run(cmd, cwd=cwd, capture_output=True, text=True, encoding="utf-8",
                       errors="replace")
    if p.stdout:
        print(p.stdout.rstrip())
    if p.returncode != 0:
        print(p.stderr.rstrip())
        raise SystemExit("실패: %s" % " ".join(cmd))
    return p.stdout


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--deploy", action="store_true")
    args = ap.parse_args()

    ver = version()
    print("버전: %s (정본은 csproj 의 <Version>)" % ver)

    run(["dotnet", "build", SLN, "-c", "Release"])

    for d in (STAGE, DIST):
        if os.path.isdir(d):
            shutil.rmtree(d)
    os.makedirs(STAGE)
    os.makedirs(DIST)

    # .gha 와 manifest.yml 은 **최상위 필수**. 나머지 하위 폴더는 보존된다.
    for name in ("AdaptiveMold.GH.gha", "AdaptiveMold.Core.dll"):
        src = os.path.join(BIN, name)
        if not os.path.exists(src):
            raise SystemExit("빌드 산출물이 없다: %s" % src)
        shutil.copy(src, STAGE)

    shutil.copy(os.path.join(REPO, "plugin", "AdaptiveMold.GH", "Resources", "icon64.png"),
                os.path.join(STAGE, "icon.png"))

    ex_dst = os.path.join(STAGE, "examples")
    os.makedirs(ex_dst)
    for p in sorted(glob.glob(os.path.join(REPO, "plugin", "examples", "*.gh"))):
        shutil.copy(p, ex_dst)

    doc_dst = os.path.join(STAGE, "docs")
    os.makedirs(doc_dst)
    shutil.copy(os.path.join(PKG, "manual.html"), os.path.join(doc_dst, "manual.html"))

    with open(os.path.join(PKG, "manifest.yml"), encoding="utf-8") as f:
        manifest = f.read()
    manifest = re.sub(r"^version:.*$", "version: %s" % ver, manifest, flags=re.M)
    with open(os.path.join(STAGE, "manifest.yml"), "w", encoding="utf-8") as f:
        f.write(manifest)

    if not os.path.exists(YAK):
        raise SystemExit("yak.exe 가 없다: %s" % YAK)
    run([YAK, "build", "--platform", "win"], cwd=STAGE)

    made = glob.glob(os.path.join(STAGE, "*.yak"))
    if len(made) != 1:
        raise SystemExit(".yak 이 하나가 아니다: %s" % made)

    name = os.path.basename(made[0])
    print("산출: %s" % name)

    # **파일명이 곧 진단이다.**
    if EXPECTED_TAG not in name:
        raise SystemExit(
            "배포 태그가 %s 가 아니다: %s\n"
            "  --platform win 을 줬는지, NuGet 이 8.0.23304.9001 로 고정됐는지 볼 것.\n"
            "  틀리면 Grasshopper 가 아무 진단 없이 등록을 거부한다 (J-015 TRAP-03)."
            % (EXPECTED_TAG, name))

    if not name.startswith("ljks-adaptive-mold-"):
        raise SystemExit(
            "패키지 이름이 ljks-adaptive-mold 가 아니다: %s\n"
            "  manifest.yml 의 name 을 확인할 것. 최초 업로드의 대소문자가 영구 고정된다."
            % name)

    final = os.path.join(DIST, name)
    shutil.move(made[0], final)
    print("[OK] %s  (%d bytes)" % (final, os.path.getsize(final)))

    if args.deploy:
        if not os.path.isdir(DEPLOY):
            os.makedirs(DEPLOY)
        shutil.copy(final, DEPLOY)
        print("배포: %s" % os.path.join(DEPLOY, name))
        print()
        print("다음은 사람이 한다:")
        print("  1. Rhino > Options > Advanced >")
        print("     Rhino.Options.PackageManager.Sources 에 다음을 세미콜론으로 추가")
        print("     %s" % DEPLOY)
        print("  2. yak cache   ← 인자를 받지 않는다. 소스 등록이 선행 조건이다.")
        print("     낡은 인덱스가 새 패키지를 감춘다 (J-015 FACT-03).")

    return 0


if __name__ == "__main__":
    sys.exit(main())
```
