# AMv1 `.gha` 포팅 — M2a 구현 계획 (툴체인·배포경로·러너·지문)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** C# `.gha` 포팅의 **기반 넷**을 세운다 — 사내 패키지 배포 경로, `plugin/` 솔루션 골격, 픽스처를 돌릴 테스트 러너, 그리고 **C# 이 파이썬과 같은 입력 지오메트리를 만든다는 증명**.

**Architecture:** `plugin/` 아래 3~4개 C# 프로젝트. `AdaptiveMold.Core` 는 RhinoCommon 만 참조하는 순수 라이브러리, `AdaptiveMold.GH` 는 얇은 `.gha` 어댑터, `AdaptiveMold.Tests` 는 골든 픽스처 대조, (필요 시) `AdaptiveMold.TestHost` 는 Rhino 안에서 테스트를 태우는 `.rhp`. 이 마일스톤에서는 **역산 알고리즘을 한 줄도 옮기지 않는다** — 옮길 자리와 옮긴 것이 맞는지 볼 수단을 만든다.

**Tech Stack:** C# / .NET `net7.0-windows` / RhinoCommon 8.x (NuGet) / Grasshopper 8.x (NuGet) / NUnit / Yak 0.15.2 / Python 2.7·3 (픽스처 도구, Rhino 안에서 실행)

**Spec:** [`docs/superpowers/specs/2026-08-14-amv1-gha-yak-design.md`](../specs/2026-08-14-amv1-gha-yak-design.md)

## Global Constraints

이 절의 값은 **모든 태스크의 요구사항에 암묵적으로 포함된다.**

- **타겟 프레임워크는 `net7.0-windows`.** `net8.0` 은 구형 Rhino 8 에서 깨진다. `net48` 은 하위호환 AppDomain 경로라 신규 개발이 갈 이유가 없다.
- **어셈블리 참조는 NuGet(`RhinoCommon`, `Grasshopper`)으로만.** `C:\Program Files\Rhino 8\...` 의 DLL 을 파일 참조하지 않는다 — 절대경로가 프로젝트에 박히면 다른 PC 에서 그대로 깨진다.
- **`AdaptiveMold.Core` 의 5대 규약** (스펙 §3.1): ① Grasshopper 미참조 ② `RhinoDoc` 미참조, **`RhinoDoc.ActiveDoc` 특히 금지**(RH-86783 으로 테스트 호스트가 죽는다) ③ `IGH_DataAccess` 미참조 ④ RhinoCommon 기하 연산은 UI 스레드에서만 ⑤ 메시지를 던지지 않고 결과 객체에 모아 돌려준다.
- **병렬화·비동기 금지.** `Task.Run`, `Parallel.For`, `GH_TaskCapableComponent` 를 쓰지 않는다. 근거와 뒤집을 조건은 스펙 §3.3.
- **인덱싱은 `idx = j * nx + i`.** 순서가 바뀌면 픽스처 대조가 전부 무의미해진다.
- **컴포넌트 이름은 `AMv1 Pins`**, 탭 `LJKS`, 서브카테고리 `AMv1`.
- **파라미터 이름은 영어 snake_case**(`target_srf`, `pin_heights` …) — 픽스처 JSON 키·C# 프로퍼티·문서에 같은 문자열이 동시에 나타나므로 번역하지 않는다. **툴팁·런타임 메시지는 한국어**, 단 파라미터명·수치·API 이름은 원문.
- **`Rhino.exe /runscript=` 로 밖에서 스크립트를 태우는 것은 안 된다** (조용히 무반응, J-005 TRAP-01). Rhino 안에서 무언가를 돌려야 하면 `mcpstart` 브리지를 쓴다.
- **작업 위치는 worktree `C:\Users\leeja\Documents\dev\26_AdaptiveMold_amv1`**, 브랜치 `feature/gha-port`. 메인 폴더(`26_AdaptiveMold_development`)는 다른 세션이 쓰고 있으므로 건드리지 않는다.
- **Rhino 를 태우는 단계 전에 그 세션과 겹치지 않는지 확인한다.** 브리지 포트는 1999 하나뿐이다.

```python
def geometry_fingerprint(geo):
    """C# 빌더가 같은 지오메트리를 만들었는지 보기 위한 지문.

    값 자체에 의미는 없다. 양쪽이 같기만 하면 된다.
    소수점 6자리로 반올림하는 이유: 부동소수 최하위 비트 차이로
    지문이 어긋나면 정작 보려던 것(스펙 해석이 다른가)을 못 본다.
    """
    brep = geo if isinstance(geo, rg.Brep) else geo.ToBrep()

    bb = brep.GetBoundingBox(True)
    amp = rg.AreaMassProperties.Compute(brep)
    ns = brep.Faces[0].UnderlyingSurface().ToNurbsSurface()

    def r3(pt):
        return [round(float(pt.X), 6), round(float(pt.Y), 6), round(float(pt.Z), 6)]

    return {
        "bbox_min": r3(bb.Min),
        "bbox_max": r3(bb.Max),
        "area": round(float(amp.Area), 6) if amp else None,
        "face_count": int(brep.Faces.Count),
        "degree_u": int(ns.Degree(0)),
        "degree_v": int(ns.Degree(1)),
        "cv_u": int(ns.Points.CountU),
        "cv_v": int(ns.Points.CountV),
    }


def plane_fingerprint(plane):
    """base_plane 은 지오메트리가 아니므로 따로 잰다. None 이면 None."""
    if plane is None:
        return None

    def r3(v):
        return [round(float(v.X), 6), round(float(v.Y), 6), round(float(v.Z), 6)]

    return {
        "origin": r3(plane.Origin),
        "x_axis": r3(plane.XAxis),
        "y_axis": r3(plane.YAxis),
        "z_axis": r3(plane.ZAxis),
    }
```

```csharp
        public override string EnglishName => "AmV1RunTests";

        protected override Result RunCommand(RhinoDoc doc, RunMode mode)
        {
            var assembly = typeof(AdaptiveMold.Tests.RhinoSmokeTests).Assembly;

            var outDir = Path.Combine(
                Path.GetDirectoryName(assembly.Location) ?? ".", "test-results");
            Directory.CreateDirectory(outDir);

            var logPath = Path.Combine(outDir, "nunit-log.txt");

            using (var writer = new StreamWriter(logPath, false))
            {
                var args = new[] { "--result=" + resultPath, "--noheader" };
                int failed = new AutoRun(assembly).Execute(args, writer, Console.In);

                writer.Flush();

                RhinoApp.WriteLine("  결과 XML : {0}", resultPath);

                return failed == 0 ? Result.Success : Result.Failure;
            }
        }

}
```

```csharp
using System;
using Rhino.Geometry;

namespace AdaptiveMold.Tests
{
    public class Fingerprint
    {
        public double[] BBoxMin;
        public double[] BBoxMax;
        public double Area;
        public int FaceCount;
        public int DegreeU;
        public int DegreeV;
        public int CvU;
        public int CvV;
    }

    /// <summary>
    /// 파이썬 dump_fixtures.geometry_fingerprint 와 같은 규칙.
    /// 값 자체에 의미는 없고 양쪽이 같기만 하면 된다.
    /// 6자리 반올림도 같게 맞춘다 — 최하위 비트 차이로 지문이 어긋나면
    /// 정작 보려던 것(스펙 해석이 다른가)을 못 본다.
    /// </summary>
    public static class GeometryFingerprint
    {
        public static Fingerprint Compute(GeometryBase geo)
        {
            var brep = geo as Brep;
            if (brep == null && geo is Surface srf) brep = srf.ToBrep();
            if (brep == null) throw new ArgumentException("Brep 으로 만들 수 없다", nameof(geo));

            var bb = brep.GetBoundingBox(true);
            var amp = AreaMassProperties.Compute(brep);
            var ns = brep.Faces[0].UnderlyingSurface().ToNurbsSurface();

            return new Fingerprint
            {
                BBoxMin = R3(bb.Min),
                BBoxMax = R3(bb.Max),
                Area = amp != null ? Math.Round(amp.Area, 6) : 0.0,
                FaceCount = brep.Faces.Count,
                DegreeU = ns.Degree(0),
                DegreeV = ns.Degree(1),
                CvU = ns.Points.CountU,
                CvV = ns.Points.CountV,
            };
        }

        static double[] R3(Point3d p) => new[]
        {
            Math.Round(p.X, 6), Math.Round(p.Y, 6), Math.Round(p.Z, 6)
        };
    }
}
```

`plugin/AdaptiveMold.Tests/TestSurfaceBuilder.cs`:

```csharp
using System;
using System.Text.Json;
using Rhino.Geometry;

namespace AdaptiveMold.Tests
{
    /// <summary>
    /// adaptive_mold/tools/dump_fixtures.py 의 _make_* / build_surface /
    /// build_plane 을 1:1 로 옮긴 것.
    ///
    /// 여기서 조금이라도 달라지면 T1~T9 대조 전체가 무의미해진다.
    /// 고칠 일이 생기면 파이썬 쪽과 같이 고치고 지문을 다시 뽑을 것.
    /// </summary>
    public static class TestSurfaceBuilder
    {
        public static Brep BuildSurface(JsonElement spec)
        {
            var kind = spec.GetProperty("kind").GetString();
            switch (kind)
            {
                case "flat":
                    return MakeFlat(
                        spec.GetProperty("z_height").GetDouble(),
                        spec.GetProperty("size").GetDouble());
                case "tilted":
                    return MakeTilted(
                        spec.GetProperty("tilt_degrees").GetDouble(),
                        spec.GetProperty("z_base").GetDouble(),
                        spec.GetProperty("size").GetDouble());
                case "hemisphere":
                    return MakeHemisphere(
                        spec.GetProperty("radius").GetDouble(),
                        spec.GetProperty("center_z").GetDouble());
                default:
                    throw new ArgumentException("unknown surface kind: " + kind);
            }
        }

        /// <summary>base_plane spec. null 이면 WorldXY 를 뜻하므로 null 을 돌려준다.</summary>
        public static Plane? BuildPlane(JsonElement spec)
        {
            if (spec.ValueKind == JsonValueKind.Null) return null;

            var kind = spec.GetProperty("kind").GetString();
            if (kind == "rotated") return MakeRotatedPlane();

            throw new ArgumentException("unknown plane kind: " + kind);
        }

        // _make_flat_surface
        static Brep MakeFlat(double zHeight, double size)
        {
            var plane = new Plane(new Point3d(0, 0, zHeight), Vector3d.ZAxis);
            var interval = new Interval(-size / 2.0, size / 2.0);
            return new PlaneSurface(plane, interval, interval).ToBrep();
        }

        // _make_tilted_surface
        static Brep MakeTilted(double tiltDegrees, double zBase, double size)
        {
            double angle = tiltDegrees * Math.PI / 180.0;
            var normal = new Vector3d(Math.Sin(angle), 0, Math.Cos(angle));
            var origin = new Point3d(size / 2.0, size / 2.0, zBase);
            var plane = new Plane(origin, normal);
            var interval = new Interval(-size / 2.0, size / 2.0);
            return new PlaneSurface(plane, interval, interval).ToBrep();
        }

        // _make_hemisphere — 이름과 달리 온전한 구를 만든다. 파이썬이 그렇다.
        static Brep MakeHemisphere(double radius, double centerZ)
        {
            var center = new Point3d(500, 500, centerZ);
            return new Sphere(center, radius).ToBrep();
        }

        // _make_rotated_plane
        static Plane MakeRotatedPlane()
        {
            var origin = new Point3d(500, 300, 100);
            var xAxis = new Vector3d(1, 1, 0);
            xAxis.Unitize();
            var yAxis = Vector3d.CrossProduct(Vector3d.ZAxis, xAxis);
            yAxis.Unitize();
            return new Plane(origin, xAxis, yAxis);
        }
    }
}
```
